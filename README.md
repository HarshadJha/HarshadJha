## 🚀 Featured Projects

### 🛡️ CrowdSafe — AI Crowd Safety System
> `Python` `YOLOv8` `PyTorch` `OpenCV` `Streamlit` `Firebase` `SMTP` `Pandas` `NumPy`

- Real-time crowd density detection using **YOLOv8** object detection on live video feeds
- Built an **Incident Management dashboard** to track, acknowledge, and resolve high-density alerts with auto-escalation
- Integrated **SMTP email alerts** for critical thresholds and persisted events to **Firebase Realtime Database**

---

### 🔍 Packet Analyzer — Node.js Deep Packet Inspection
> `Node.js` `JavaScript (ES6+)` `PCAP` `Streams` `Buffer`

- Architected a **zero-dependency DPI system** that reads PCAP files and parses Ethernet, IPv4, TCP, and UDP layers
- Extracted **SNI from TLS handshakes**, HTTP Host headers, and DNS queries
- Built a **rule engine** for traffic classification — block by app, source IP, or domain; generates forwarded-vs-dropped reports

---

### 📲 UPI Without Internet — Offline Payment Simulation
> `React (v18)` `Node.js` `Express.js` `MongoDB` `Mongoose` `Node.js crypto` `UUID`

- Full-stack app simulating **offline UPI payments** via a Bluetooth-style device-to-device mesh network
- Secured all payment packets with **Node.js native end-to-end encryption** and a store-and-forward relay architecture
- Express.js + MongoDB backend handles **decryption, deduplication, and settlement** with a React frontend for real-time tracking
